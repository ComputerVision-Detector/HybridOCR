# HybridOCR: 복합 필기 문서의 OCR 정확도 개선 및 시각적 구조·관계 복원 시스템

촬영한 한글·영문 혼합 필기노트를 대상으로 문자 인식 오류를 줄이고, 화살표 연결 및 박스 포함 관계를 복원하는 시제품입니다. 이미지 보정, 영역별 OCR, 좌표 기반 구조 분석을 결합하여 원본 문서의 정보와 시각적 관계를 유지한 JSON 및 Markdown 형태의 결과물을 제공합니다.

---

## 1. 프로젝트 배경 및 필요성

* **복합 문서 인식 오류:** 손글씨, 인쇄체, 수식, 표, 도형 등이 혼재된 필기노트에서는 기존의 단순 문자열 추출 방식만으로는 정확한 정보 파악이 어렵습니다. 문자와 도형의 겹침, 영역 경계의 불명확성 문제를 해결하기 위해 텍스트 영역 분리와 사전학습 OCR의 결합이 필요합니다.
* **촬영 환경에 따른 품질 저하:** 원근 왜곡, 그림자, 흐림 등 촬영 시 발생하는 품질 저하를 보완하기 위한 선택적 이미지 전처리가 요구됩니다.
* **시각적 구조 및 관계 정보 손실:** 단순 텍스트 인식만으로는 화살표의 방향(출발/도착)과 박스 안의 포함 관계 등 작성자의 시각적 의도가 유실됩니다. 위치와 방향에 근거한 명시적 관계 복원이 필수적입니다.

## 2. 주요 기능 및 모듈 파이프라인

본 시스템은 `문서 입력 → 선택적 이미지 보정 → 구성요소 검출 → 영역별 OCR → 읽기 순서 및 관계 분석 → 구조화 결과 생성`의 파이프라인으로 동작합니다.

* **이미지 전처리 모듈:** 회전, 원근, 밝기 보정을 수행하며, 입력 품질이 현저히 낮아 복원이 불가능한 경우 재촬영 안내 상태로 분류합니다.
* **문서 구성요소 검출 모듈:** Text, Arrow, Box 영역의 위치와 유형을 검출합니다. 수식, 표, 도형 등은 비텍스트 영역으로 분류하여 원본 이미지 조각 상태를 보존합니다.
* **영역별 OCR 모듈:** 한글 지원 사전학습 OCR 모델을 검출된 텍스트 영역에 적용합니다.
* **읽기 순서 분석 모듈:** 단/열 배치의 텍스트 위치 좌표를 기준으로 순서를 추정합니다. 비선형 필기의 경우 판단 가능한 선후 관계 및 영역 묶음으로 제공합니다.
* **구조·관계 복원 모듈:**
* 연결 관계: 화살표 끝점, 방향, 주변 영역을 분석하여 출발지에서 도착지로의 관계를 추정합니다.
* 포함 관계: 박스와 영역 간의 중첩 정도를 분석하여 종속 관계를 구성합니다.


* **결과 출력 모듈:** 요소 ID, 유형, 좌표, 문자, 순서, 관계가 포함된 JSON 데이터와 원본 맵핑 및 이미지 조각이 배치된 Markdown 문서를 최종 생성합니다.

## 4. 평가 지표

목표 성능은 직접 OCR 적용 대비 오류율(CER) 상대 10% 감소 및 관계 F1 Score 0.70 이상으로 설정되었습니다.

* **문자 인식 (CER):** `(치환 + 삭제 + 삽입) / 정답 문자 수` (한글 NFC, 공백, 문장부호 정규화 규칙 적용)
* **요소 검출 (Detection):** 클래스별 AP 및 mAP@0.5
* **관계 복원 (Relation):** 예측된 요소가 정답과 일대일 대응(IoU ≥ 0.5)되며, 관계 유형 및 방향까지 일치할 때 정답으로 판정하여 Precision, Recall, F1 Score를 산출합니다.
* **읽기 순서:** 명확한 정답 요소 쌍 간의 선후 일치율을 기준으로 평가합니다.

## 5. 개발 및 추진 일정

* **1~3주차 (데이터 수집 및 기준 확정):** 공개 자료 및 직접 촬영 문서 200쪽 구축 (학습 120, 검증 40, 테스트 40 분할). 동일 원본의 증강본 및 재촬영본은 동일 분할 내에 배치.
* **4~6주차 (라벨링 및 검출 모델 설정):** Text, Arrow, Box 영역, 문자 정답, 선후 및 포함 관계 라벨링 수행. 교차 검수를 통한 데이터 정제 및 전처리/검출 파라미터 확정.
* **7~9주차 (OCR 인식 및 결과 통합):** 사전학습 OCR 연동 및 원본 좌표 복원. 비텍스트(Formula, Table, Diagram) 영역의 이미지 보존 처리.
* **10~12주차 (구조 복원 및 시연 구현):** 화살표/박스 기반 논리 구조 분석 후 JSON 및 Markdown 출력 기능 구현. 웹 기반 시연 화면 개발 및 통합 오류 사례 분석.
* **13~15주차 (통합 평가 및 결과 정리):** 고정된 테스트 데이터를 활용한 최종 성능 평가(CER, mAP, F1 산출). 연산 시간 및 난이도별 한계점 분석 보고서 작성.
